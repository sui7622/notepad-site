Core

先把「记事本」这件事做对

打开、编辑、保存、不丢内容——这四件事没有捷径。下面每一条都能在程序里点出来验证。

真写盘，不是假保存

主进程用 fs 落盘 UTF-8 纯文本。只有字节真的写进去了，界面才敢提示「已保存」。

fs.writeFileUTF-8错误原样上报

关窗口前一定问你

新建、打开、拖入文件、关闭窗口都会拦截，弹「保存 / 不保存 / 取消」。选取消，文档和窗口都留着。

四处拦截三选项

多文件侧边栏

打开过的文件列在左侧，单击切换。重命名、删除（进回收站，不是直接抹掉）都在条目上右键。

shell.trashItem切换不丢草稿

会话记得住

退出时把文件列表、当前文档、未保存的草稿写进 open-files.json，下次启动原样恢复。

open-files.json草稿 1MB 上限

页面碰不到磁盘

contextIsolation 开、nodeIntegration 关、sandbox 开。渲染进程没有 require，preload 只放出白名单方法。

contextBridgeIPC 白名单

拖进来就打开

把文件从资源管理器直接拖进窗口，松手前有全屏虚线提示框。打开前照样先问未保存的内容怎么办。

webUtils.getPathForFile多文件支持
Personal

界面是你的，想怎么摆就怎么摆

主题、字体、面板宽度全都可调，调完写进 settings.json，重开还是你上次的模样。

四套预设 + 自由配色

默认、深色、森林、落日四套卡片一键切换；不够就打开取色板，9 个 CSS 变量逐个取色，实时预览。

4 预设9 变量取色切换不重置字体

字体、字号、行高

字体族下拉六选（系统等宽 / 雅黑 / 宋体 / Consolas…），字号 10–32、行高 1.0–3.0 步进调节，编辑区即时重排。

--editor-font-size实时预览

两边都能拖着调

左侧文件栏、右侧 AI 面板的边缘都能按住拖，中间编辑区自动让位。宽度记住，下次启动原样恢复。

AI Writing

六项 AI 能力，
一条「先预览、再决定」的规矩

摘要、润色、翻译、提纲、思维导图、文生图。所有结果先落在预览框里——只有你点了「替换选中」，正文才会动。

摘要把选中内容压成几条要点
润色改病句与行文，保持原意
翻译中英互译，保留原有分段
提纲给出标题 + 结构化提纲
思维导图整理成层级大纲
文生图DeepSeek 写提示词，生成配图可存盘
01选中文字没选中就提示先选，不偷偷处理全文
02发起请求主进程代发网络请求，渲染层不碰 Key
03预览结果结果落在预览框，可直接改
04决定去向复制 / 插入到选区后 / 替换选中 / 取消
底线：API Key 只存本机 %APPDATA% 下的 ai-config.json；不配 Key 时其余功能完全离线——编辑、保存、主题、快照一个都不少，不发任何网络请求。
Everyday

写着写着，会离不开的几个小东西

都不是花架子，是每天真的会用到的路径。

查找条

Ctrl+F 唤起，边打边跳，上一个 / 下一个切换，走到末尾自动回到开头。

撤销与重做

工具栏和菜单双入口，Ctrl+Z / Ctrl+Y 和系统编辑行为一致。

状态栏实时统计

字数、行数、当前文件路径与「未保存」红点，一直在底部躺着，不抢视线。

原生菜单

文件 / 编辑 / 视图三组菜单，标准编辑项直接用系统 role，行为跨平台一致。

未保存红点

标题、侧边栏条目、状态栏三处同步标记，有没有改过一眼看得见。

非法文件名当场拦

重命名时带 \ / : * ? " < > | 会被拦下并说明原因，不用等写盘失败才发现。
